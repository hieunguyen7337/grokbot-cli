# Run control

| Key or command | Effect | App name |
|---|---|---|
| Ctrl+X | Stop the selected working bot, or the current session's run. | Stop |
| `/interrupt` | Stop the selected bot or current session. | Stop |
| `/fresh` | Confirm and start a new conversation. | Reset |
| `/rollback` | Confirm and roll back the last turn, restoring your last message to the session composer. | Edit |

On home, stopping targets each running session, or the main chat when none are listed. Ctrl+X remains an input editing key when the bot is idle. Conversation updates arrive through live events.
